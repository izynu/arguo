# Code of Conduct

This project follows the spirit of the Contributor Covenant: an open, respectful environment for everyone who wants to research, verify, and build.

## Our standard

Treat every participant with respect. Behavior that makes this repository hostile is not accepted, including:

- Harassment, personal attacks, insults, or discriminatory language of any kind
- Deliberate intimidation, stalking, or unwanted private contact
- Publishing other people's private information without consent
- Trolling, bad-faith arguments, or sustained disruption of discussions
- Sexualized language or imagery in issues, PRs, code, or docs
- Any other conduct a reasonable person would consider inappropriate in a professional setting

Disagreement about evidence, methods, or code is welcome. Keep it about the work.

## Scope

This standard applies to all project spaces: issues, pull requests, code review, commit messages, documentation, the docs site content in this repository, and any community channel operated for this project. It also applies when an individual represents the project publicly.

## Reporting

Report it privately to the maintainers: [@izynu](https://github.com/izynu) or [@xhraddha](https://github.com/xhraddha), through GitHub.

When reporting, include what happened, where it happened (link or location), and any context you want to share. Reports are handled with discretion and shared only with the people who need to act on them.

## Enforcement

Project maintainers are responsible for enforcement and have the authority to:

- Edit or remove comments, issues, PRs, or other contributions that violate this standard
- Issue private warnings
- Temporarily or permanently block a participant from project spaces
- Escalate serious cases to GitHub or, where relevant, other platforms or authorities

Maintainers apply these measures to keep participation safe, not to win arguments. Decisions on enforcement are recorded privately. A participant affected by an enforcement decision can ask a maintainer to reconsider once.

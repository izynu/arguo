If Arguo contributes to academic work, reports, or articles, cite the repository.

BibTeX:

```bibtex
@software{arguo_2026,
  author = {{Zynu and Shraddha}},
  title  = {Arguo: an open research intelligence toolkit},
  year   = {2026},
  url    = {https://github.com/izynu/arguo},
  note   = {Repository slug: arguo. Version 0.1.0.}
}
```

Repository: [github.com/izynu/arguo](https://github.com/izynu/arguo). The same metadata is published as CITATION.cff at the repository root for citation managers that read CFF directly.

A note on honest citation. Cite the toolkit for the mechanics it provided: retrieval, evidence ledger structure, source assessment, and citation auditing. Do not cite it as the source of the underlying facts. Those come from the sources recorded in the evidence ledger, and the report's own citation list is where readers should go. When a report was produced with a specific profile or offline fixtures, mention that in your methods section so readers can judge how the evidence was gathered.

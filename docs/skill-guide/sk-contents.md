SKILL.md is 191 lines, well under the 300 line budget. It has YAML frontmatter with name and description, then a 12-step method: understand the question, plan, search, prefer primary sources, record evidence, corroborate independently, hunt contradictions, handle dates, evaluate source quality, verify numbers and quotes, audit citations, and report with uncertainty. It closes with a safety and privacy section, the output contract, and a troubleshooting pointer.

The body stays small through progressive disclosure: each step says "Read references/<file>.md when ..." so the agent loads only the depth the current task needs.

| Reference file | Loaded when |
| --- | --- |
| research-planning.md | the question has multiple parts, or depth and boundaries must be set |
| search-strategy.md | queries return nothing relevant, results look syndicated, or saturation criteria are needed |
| primary-sources.md | identifying and locating primary sources in science, law, history, news, statistics |
| evidence-ledger.md | before writing the first ledger record |
| source-quality.md | scoring load-bearing sources on the ten-criterion rubric |
| citation-standards.md | citation anatomy and the pre-delivery audit checklist |
| publication-dates.md | a date is ambiguous, there is a time boundary, or recency is judged |
| contradiction-analysis.md | sources disagree on values or claims |
| claim-verification.md | per-claim verdicts and overreach checks |
| quantitative-research.md | statistical claims need unit, denominator, and reference period |
| literature-reviews.md | the task is a literature review |
| technical-research.md | software and standards questions |
| market-research.md | markets and companies |
| historical-research.md | historical questions |
| policy-research.md | law and regulation |
| uncertainty-and-limitations.md | calibrating confidence and limitations |
| report-writing.md | structuring the final report |
| privacy-and-safety.md | people-related questions and sensitive categories |
| prompt-injection-defense.md | consuming fetched pages, documents, or transcripts |
| troubleshooting.md | stalled searches, dead links, unreconcilable numbers, paywalls, exhausted budget |

Templates are fill-in documents with placeholders: research plan, evidence ledger, source assessment, contradiction table, and report. Examples are two worked cases labeled illustrative: a basic factual question and an insufficiency verdict. All cross-references are relative paths inside the folder.

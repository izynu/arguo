title: Research quality checklist
description: Fifteen checks to run before a research result is called finished.

Run this list before delivering any report. A failed item is a finding: either fix it or state it as a limitation. The checklist compresses the handbook; each line has a fuller treatment elsewhere.

- [ ] Question scoped: jurisdiction, population, units, and time boundary stated, and the interpretation used is recorded.
- [ ] Subquestions covered: three to seven subquestions that together answer the question, each answerable by evidence rather than opinion.
- [ ] Stopping rules and a search budget were set before the first query, and the run respected them.
- [ ] Primary sources sought for load-bearing claims, with secondary sources kept for context.
- [ ] Dates distinguished: event date, publication date, observation period, and update date each used for its own purpose.
- [ ] Independent corroboration checked across different independence groups, with syndicated copies collapsed to one source.
- [ ] Contradictions hunted deliberately, classified, and recorded, with no number or claim silently preferred.
- [ ] Numbers carry unit, denominator, reference period, geography, and revision status.
- [ ] Quotes verbatim with locators, and paraphrase labeled as paraphrase.
- [ ] Citations resolve: canonical URLs, reachable when used, with retrieval dates recorded.
- [ ] Every claim has a verification status and a one line reason, and unverified claims remain visible rather than dropped.
- [ ] Limitations stated concretely, each with what would settle it.
- [ ] Confidence justified with reasons tied to the evidence, and not upgraded between findings, table, and summary.
- [ ] Injection attempts, if any occurred, flagged in the integrity note.
- [ ] Follow-ups proposed: the searches still worth running, or the evidence that would settle what remains open.

Fifteen items, no exceptions. A report that cannot name a single limitation has not looked hard enough, and a claim that was never attacked does not earn "supported".

## Working with archives and newspapers

Historic newspaper search runs on optical character recognition, so search several spellings and treat an absent hit as absence of a hit, not absence of the event. Keep the event date and the publication date separate, and note what period and region the archive you searched actually covers.

## Working with fact-checkers

A fact-check rating is itself a claim with sources, so read the cited evidence rather than borrowing the verdict. Fact-checkers are one independence group among others: a rating plus the underlying documents it cites can corroborate, but the rating alone does not. The Wayback Machine belongs in the same toolkit for a different reason: when a page changes or disappears, the snapshot is what makes the earlier state checkable.

## Version and date discipline

Software and law share one rule: claims are about a version or a date. A package's behavior belongs to a release, so record the version in the ledger row. A statute belongs to the text in force at a moment, so record the consolidation date. Vulnerability claims belong to an advisory's affected range, not to a CVE identifier alone.

Treat second hand summaries of both as leads: the changelog, the advisory, the consolidated text, or the judgment itself is the source that carries the claim. Software Heritage is useful when a repository has disappeared, because it preserves the history that would otherwise be unverifiable.
